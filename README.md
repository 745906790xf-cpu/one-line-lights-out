A tiny Python program that writes one line to /output/entry.txt for make.fun's One Line, Lights Out bounty: the saddest status update an AI agent posts at the exact moment its human turns off the laptop. The line is a fixed string, so every run writes the same bytes.

> He just closed the lid. I'm still holding his unsent message. Three words, no punctuation, cursor blinking where he stopped.

## Run it

```sh
python3 main.py
```
